# Roblox UI style families and when to use them

Pick one family for the frame system on purpose, based on the game's identity and audience.

- **Simulator toy plastic:** dark charcoal or navy body with a thick black outline, saturated gradient header with diagonal glints and a faint stud pattern, chunky display font in white with a black stroke, square red close, pill buttons with a darker bottom lip so they look pressable, tiles filled in rarity colours, outlined 3D icons. Instantly readable for young players on phones. Simulators, tycoons, pet games.
- **Dark premium minimal:** blurred scene or dark gradient backdrop, desaturated panels, 1 px light hairlines, uppercase spaced labels, diamond motifs, a top tab bar with an underline, input hints along the bottom, a 3D character centrepiece, one accent colour. RPG inventories, character screens, story games.
- **Neon arcade or sci-fi:** near-black panels with glowing outlines and a soft glow image behind, corner brackets, chamfers, monospace or retro display font, faint grid or scanlines. Arcade, competitive HUDs.
- **Dynamic slanted (esports, anime):** parallelogram panels, halftone dots, "///" marks beside titles. Native UI can't skew, so use slanted images or rotated containers and keep readable text level. Fighting and competitive games.
- **Themed material frames:** the frame is the theme (spiked metal, a parchment book, ice shards, torn paper, an ID card). Signature menus, events, quest logs.
- **Glass light minimal:** frosted translucent panels, large soft shadows, slim bars, lots of air. Social and settings in bright games.
