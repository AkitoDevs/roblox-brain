# One chassis, a metaphor per screen

How to make every window memorable and self-explanatory while all of them clearly belong to one system.

**Why it works**
1. **One chassis, many places.** Every window shares the same frame: a dark angled panel, a left rail with a ring and the section icon, a small index-number tab, a tiny meta label above a big heavy italic title, count and status chips, skewed tabs at the top right, a round red close on the corner. Players learn the controls once, so the inside of each window is free to differ.
2. **A metaphor per screen explains the function without words:** a field dossier for the collection index, a transit terminal for travel, a tune-up bench for upgrades, a curio cabinet for items, a console for settings.
3. **Small authentic details sell it:** file numbers, barcodes, rubber stamps, tape, polaroids, sticky notes, speaker grilles, knobs, LCD counters. Small, low contrast, never on top of content.
4. **Dense but legible:** big values with small uppercase captions, and every abbreviation explained once by a short legend line along the bottom (for example what solid and dashed lines mean).
5. **State is always on screen:** the player's current position, what is open, the missing requirement in red with its number, a completion stamp, locked cards that say what comes next, gold corner brackets on the selection, check badges, NEW ribbons.
6. **Slant adds energy** to dark, dense screens: italic titles, parallelogram tabs, angled row ends.
7. **One accent does the work:** gold for the primary action and selection, red for close and delete, green for open and on; rarity colours fixed and explained in a legend.

**Applying it**
1. Design the chassis first and freeze it (rail, header, tabs, close, footer, button and chip styles).
2. For each window pick an object from the game's own world that matches the job: ordered progress = a route; completion = a dossier; levels = gauges; owned things = a cabinet; tasks = a notice board; odds and pulls = an altar plaque; timed expeditions = a departure board.
3. Let the metaphor shape the layout, not just the decoration. Keep numbers, buttons and states in the shared component style so the window still reads instantly.
4. Add the details last, small and quiet, and check every window at phone size (text at least about 14 px, tap targets about 44 px).
