# Name the defaults before you build a screen

Write a style sheet first, then build.

1. **Style sheet:** shape language, palette, fonts, materials and detail level, written down before the first frame exists.
2. **Name three to five generic defaults to avoid, each with a reason.** For example: the stock font on a grey panel reads as a template; a purple-blue gradient is the stock generated look; evenly sized cards in a plain grid have no hierarchy; one rainbow accent hides the primary action.
3. **Build ONE hero screen and get it approved,** then batch the remaining screens, changing one thing per batch.
4. **Refine about two passes with specific feedback,** then fix the brief or start fresh rather than iterating a third time on the same prompt.
