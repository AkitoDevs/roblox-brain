# More Roblox UI style families

- **Tactical glass HUD:** 40 to 60% opaque slate panels over the live scene, 1 px borders with corner ticks, one hot accent, big numerals over small captions, data tables with green and red deltas, keybind chips in a footer. Shooters, looters, stat-heavy loadouts.
- **Ink-brush cinematic:** near-black canvas, one saturated accent, slanted brush-stroke menu bars, a huge two-line title, a faint giant emblem watermark. Main menus and character select.
- **Desktop metaphor:** the menu is a desktop of app icons with hotkey letters, the shop is a browser window, sticker badges and a friendly lowercase font. Party and self-aware games.
- **Pixel arcade:** pixel font with a hard drop shadow, stacked tilted menu words as the buttons, a rotating sunburst sky. Party and retro games.
- **Arcade showcase:** chunky top nav with icons breaking out, a big showcase card beside a rarity-gradient grid, a stats panel and one wide state button. Weapon, pet or unit upgrade screens.
- **Dark data rows (ledger):** near-black angled rows with a coloured index tab, value-over-caption columns, rarity pills, the selected row expanding inline. Collections past about 40 items.
- **Anime glow:** charcoal panel with a gradient border, a painted header bursting from a corner, rarity-coloured glows behind the grid and detail panel. Unit and hero inventories, summon banners.
- **Pixel-art gothic:** small pixel frames 9-sliced with Pixelated resampling and integer SliceScale, grunge fills, a restricted palette, ornaments pinned to frames. Dark fantasy and roguelikes.

Mixing example: premium navy-and-gold frames plus simulator colour semantics, tile states and juicy feedback suits a fantasy idle RPG on mobile.
