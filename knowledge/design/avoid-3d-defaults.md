# Directed, not assembled: avoiding 3D defaults

A game can work and still look flat and unappealing because it was assembled rather than directed: no stated look, default lighting on a bare baseplate, saturated colour on every surface, and detail placed before mood.

**Decide the look first.** Write one line before building: what kind of scene, for whom and on what device, in what visual language and world (for example warm stylised fantasy, neon night sci-fi, cozy toy-like simulator). Take it from the request, references and existing assets, not habit. A pinned style, palette or reference always wins.

**Refuse these defaults unless asked for**
- A bare baseplate and the default sky; default lighting with no key light, no Atmosphere and no grade.
- Every surface saturated, each part its own colour. Use one dominant colour family, one secondary and one accent.
- Neon as decoration: glowing strips and halos that light nothing. Use neon only where a real source exists, darkened so it doesn't bloom to white, and paired with a real light.
- Raw primitives standing in for designed shapes: perfect spheres, untrimmed boxes, uniform cylinders.
- Perfect grids of identical items in a world that isn't formal; rows of same-size buttons as the whole layout.
- Uniform scatter like a carpet, flat undressed ground, objects resting on the ground instead of growing out of it.
- Default fonts as the display voice, emoji as icons, gradient text, blur as decoration.
- Accidental default chrome: the skybox, spawn pad, leaderboard, chat bubbles, loading screen and cursor still carry the look. Theme them or deliberately hide them.
