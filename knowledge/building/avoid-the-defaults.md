# Name the defaults before you build a model

Generic output comes from unnamed defaults, so name them first.

1. **Write a short style sheet:** shape language, three or four colour roles, materials, detail level, and what must never appear.
2. **List three to five generic defaults to avoid, each with a reason.** For example: plain grey boxes read as unfinished; one saturated neon hue flattens depth; evenly spaced identical props look generated; symmetric centred layouts look templated.
3. **Build ONE hero asset and get it approved before any batch.** Then change one thing per batch so you can see what each change did.
4. **Refine about two passes with specific feedback** (what differs from the reference). If a third pass does not help, fix the brief or start a fresh session instead of pushing harder.
