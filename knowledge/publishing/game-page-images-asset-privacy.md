# Game page images and asset privacy

Labelled **Unverified tip:** one developer's report, not checked by us.

- **Unverified tip:** an experience icon or thumbnails can be approved and work in game, yet show a grey box on the public game page when the images are Restricted under asset privacy.
- **Unverified tip:** set those images to Open Use (use granted to everyone) in the Creator Dashboard or through the asset permissions API. Granting access to the experience only does not help.
- **Unverified tip:** if an image's own asset thumbnail shows the private placeholder, it is Restricted.
- **Warning:** the change to Open Use cannot be undone. Make sure you are happy for anyone to use the image first.
