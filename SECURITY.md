# Security Policy

Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Please include what you found, how to reproduce it, and what you think the impact is. This is a small volunteer project, so replies may take a few days.

## What counts

Examples: a way to make the plugin leak your code or personal data in a shared tip, bypass the sharing opt-out, or abuse the tip inbox.

See [PRIVACY.md](PRIVACY.md) for what the plugin shares and how to delete it.
