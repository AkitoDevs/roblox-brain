# Contributing to Roblox Brain

Thanks for helping! Roblox Brain is a free, early-development Claude plugin with generic Roblox knowledge.

## Easiest ways to help

- Use the plugin with tip sharing on. Reviewed tips from real projects are the best source of new knowledge.
- Report bugs or wrong advice by opening an issue.
- Suggest knowledge you think is missing.

## Pull requests

1. Fork the repo and create a branch.
2. Keep knowledge entries generic and in your own words. Do not paste code, names, ids or links from private projects, and do not copy other people's work.
3. Run `npm test` before opening the pull request.
4. Describe what changed and why.

Small, focused pull requests are easiest to review.

## Conduct and security

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). To report a security problem, see [SECURITY.md](SECURITY.md).
